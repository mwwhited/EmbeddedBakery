# STM32F103C8 Projects

Projects for the STM32F103C8T6 "Blue Pill" development board.

## Hardware

- MCU: STM32F103C8T6 (ARM Cortex-M3)
- Clock: 72 MHz max
- Flash: 64KB
- RAM: 20KB
- Built-in LED: PC13 (active low)

## Blink

Basic LED blink test. Toggles the built-in LED on PC13 with a pattern:
- 1 second on, 1 second off
- 10 rapid blinks (100ms each)
- Repeat
