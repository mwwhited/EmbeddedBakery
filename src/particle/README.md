# Particle IoT Projects

Projects for Particle IoT devices (Photon, Electron, Argon).

## Projects

### HelloWorld
Basic "Hello World" project for Particle devices.

### SubController
Sub-controller implementation for distributed IoT systems.

## Development

Use:
- Particle Web IDE (build.particle.io)
- Particle Workbench (VS Code extension)
- Particle CLI

## Build

```bash
particle compile photon <project>
particle flash <device> <binary>
```
