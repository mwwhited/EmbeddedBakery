Ball-in-Maze game for Tahoe-II
==============================

This game shows how to use the sampling mode of the on-board accelerometer.
It is based on the orginal version for Tahoe.  For more details download the lab instructions from:
http://devicesolutions.net/Support/Downloads.aspx


How to play:
------------

Tilt the board to guide the ball through the maze.

Buttons:
SW1: Re-calibrates the accelerometer
SW5: Changes the ball color
SW7: Starts a new game with new maze
