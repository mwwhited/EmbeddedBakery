# Basic Stamp Projects

Projects for Parallax Basic Stamp microcontrollers.

## Files

### blink_test.bs2
Simple LED blink test program.

### fmradio.bs2
FM radio control program.

### fmradio_i2c.bs2
FM radio control via I2C interface.

### IRPD.bs2
Infrared proximity detector program.

### spiWatcher.bs2
SPI bus monitor/watcher.

### phase1-v0.1.bs2, phase1_ai.bs2
Phase 1 project iterations.

### us_first_mwhited_01.bsx
FIRST Robotics competition program.

## Folders

### Phase1
Phase 1 project files.

### vs1011e
VS1011e audio decoder interface.

## Development

Use Parallax Basic Stamp Editor or BASIC Stamp Windows Editor.
