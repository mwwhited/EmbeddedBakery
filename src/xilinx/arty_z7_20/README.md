# Arty Z7-20 Projects

Projects for the Digilent Arty Z7-20 development board.

## Hardware

- **SoC**: Xilinx Zynq-7020 (XC7Z020CLG400-1)
- **ARM Cores**: Dual-core ARM Cortex-A9
- **FPGA**: Artix-7 equivalent programmable logic
- **Memory**: 512MB DDR3

## Projects

### helloworld
Basic Zynq "Hello World" project demonstrating PS (Processing System) and PL (Programmable Logic) integration.

### HLS-Tiny-Tutorials
Vivado High-Level Synthesis (HLS) tutorial projects. Learn to create hardware accelerators from C/C++ code.

## Development

Requires:
- Vivado Design Suite
- Vitis IDE (for software development)
