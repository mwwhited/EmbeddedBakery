# XC9500 CPLD Projects

Projects for Xilinx XC9500 series CPLDs.

## Hardware

- **Device**: XC9500 family CPLD
- **Development**: Xilinx ISE Design Suite (legacy)

## Projects

### Multip
Multiplexer designs.

### calc
Calculator logic implementation.

### pldt1
PLD test project.

### sch
Schematic-based designs.

### TestXilinx
Test and verification projects.

## Development

These projects use the legacy Xilinx ISE Design Suite. XC9500 devices are not supported by Vivado.
