# ESP-01 Blink Test

Basic ESP-01 module LED blink test.

## Description

Simple blink test for ESP-01 (ESP8266) module. Toggles GPIO2 LED and outputs messages to serial.

## Hardware Requirements

- ESP-01 module

## Pin Configuration

| Function | GPIO |
|----------|------|
| LED      | 2    |

## Serial

- Baud rate: 115200
