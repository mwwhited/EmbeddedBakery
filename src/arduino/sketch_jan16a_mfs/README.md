# Multi-Function Shield Demo

Multi-Function Shield demonstration with MPU6050.

## Description

Test sketch for the Arduino Multi-Function Shield featuring beep patterns and timer control. Includes MPU6050 gyro library (unused in main demo).

## Hardware Requirements

- Arduino Uno
- Multi-Function Shield
- Optional: MPU6050 gyro module

## Dependencies

- MultiFuncShield
- TimerOne
- Wire
- MPU6050 (optional)

## Features

- Beep control with customizable patterns
- Multiple beep cycles with configurable timing
