# Max7219x4

MAX7219 LED matrix display demo.

## Description

Demonstration code for driving LED matrix displays using MAX7219 LED driver chips. Supports multiple cascaded displays.

## Hardware Requirements

- Arduino Uno or compatible
- MAX7219 LED matrix module(s)

## Dependencies

- LedControl or similar MAX7219 library
